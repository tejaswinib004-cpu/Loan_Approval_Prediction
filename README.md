# Loan Approval Prediction

This project is developed using Machine Learning and Streamlit.  
The system predicts whether a loan will be approved or not based on applicant details.

---

# 📌 Project Features

- Data Preprocessing
- Handling Null Values
- Outlier Detection & Removal
- Feature Engineering
- Feature Scaling
- Logistic Regression Model
- Model Evaluation
- Streamlit Frontend Application
- Loan Prediction System

---

# 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Pickle

---

# 📊 Machine Learning Steps

1. Load Dataset
2. Understand Dataset
3. Data Visualization
4. Handle Null Values
5. Find & Remove Outliers
6. Feature Engineering
7. Feature Scaling
8. Train Test Split
9. Logistic Regression Model
10. Model Evaluation
11. Prediction
